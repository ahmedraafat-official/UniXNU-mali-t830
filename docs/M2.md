# M2 — T830 read-only probe on SM-T585

Date: 2026-11-18. Device: Samsung Galaxy Tab A 10.1 (2016) LTE, SM-T585
(`gtaxllte`, Exynos 7870). Kernel: UniXNU prelinked iPadOS 17.7.11 kernel with
the read-only T830 probe linked into the display archive.

The probe runs after `NativeLegacyDisplay::start`, reads the G3D power domain,
`CMU_G3D` and the GPU registers, and panics so the no-UART tablet reports the
values on the panic screen. It writes no register.

## Values

```text
pd control        0x0000000f
pd status         0x0003000f     G3D domain on
CMU_G3D mux       0x00200000
CMU_G3D divider   0x00000000
CMU_G3D gate      0x000001ff / 0x0000007f
GPU_ID            0x08300010     product 0x0830, revision 0x0010 (r0p1)
GPU_L2_FEATURES   0x07100206
GPU_CORE_FEATURES 0x00000000
```

The T830 product ID, the G3D domain and the clock gates are therefore readable
without any power/clock write at UniXNU handoff. The values are from the panic
photograph `phase0/mali1-r270.jpg` in the gtaxllte workspace.

## What this establishes

- The Mali-T830 is present at `0x11400000` and responds to reads.
- The G3D domain is already powered on when the display driver starts.
- `CMU_G3D` is clocked; the GPU gates are open.
- `GPU_ID` decodes as the expected T830 (`0x0830`, r0p1).

## What it does not establish

- No GPU write, soft reset, MMU enable, job or fence has run.
- The display path is the firmware GOP/CPU renderer; nothing in the image uses
  the GPU yet.
- The visible iPadOS UI still needs the missing iPad Data/Preboot seed.
